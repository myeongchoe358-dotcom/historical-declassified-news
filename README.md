## 🌍 全球历史解密信息收集系统

一个智能化的系统，用于收集全球已公开的历史解密文件，并每日推送到你的邮箱，支持短视频字幕文案生成和关键事件时间线提取。

### 📋 功能特性

- ✅ **多源数据爬取**：从美国国务院、CIA、NSA、BBC、History.com等多个官方来源爬取已公开的解密文件
- ✅ **智能分类整理**：自动按照政治、战争、经济、社会、科技等5个主题分类
- ✅ **每日定量推送**：每天自动收集15条信息（政治5条、战争5条、经济3条、社会1条、科技1条）
- ✅ **字幕文案生成**：自动为每条信息生成短视频友好的字幕文案
- ✅ **事件时间线提取**：自动提取日期、地点、人物、关键事件等信息
- ✅ **邮件推送**：每天定时发送格式化的HTML邮件
- ✅ **数据去重**：自动检查重复数据，避免重复推送

### 🚀 快速开始

#### 1. 环境要求
- Python 3.8+
- SQLite3
- SMTP邮件服务

#### 2. 安装依赖

```bash
pip install -r requirements.txt
```

#### 3. 配置环境变量

复制 `.env.example` 为 `.env`，填入你的配置信息：

```bash
cp .env.example .env
```

编辑 `.env` 文件：
```
EMAIL_ADDRESS=myeongchoe358@gmail.com
SMTP_PASSWORD=your_app_password_here
```

> **Gmail用户提示**：需要生成[应用专用密码](https://support.google.com/accounts/answer/185833)

#### 4. 初始化数据库

```bash
python data_crawler.py
```

#### 5. 测试运行

```bash
python scheduler.py test
```

#### 6. 启动定时任务

```bash
python scheduler.py
```

### ⚙️ 配置说明

#### config.py 中的关键配置

**内容分布比例**（每日15条）：
```python
CONTENT_DISTRIBUTION = {
    'politics': 5,      # 政治：5条
    'war': 5,          # 战争：5条
    'economy': 3,      # 经济：3条
    'society': 1,      # 社会：1条
    'technology': 1,   # 科技：1条
}
```

**数据源列表**（支持的数据源）：
- 美国国务院解密文件库
- 美国FOIA档案库
- CIA解密文件库
- NSA解密文件库
- BBC历史档案
- History.com
- 英国解密文件中心
- 俄罗斯国家档案库

**定时任务时间**（scheduler.py）：
```python
scheduler.start(
    crawl_time='08:00',      # 每天早上8点爬虫
    process_time='12:00',    # 每天中午12点处理
    email_time='18:00'       # 每天下午6点发送邮件
)
```

### 📧 邮件格式

邮件包含以下内容：

1. **文章标题** - 清晰的标题
2. **原文内容** - 完整的原文信息
3. **来源标注** - 数据来源和发布日期
4. **原文链接** - 指向源文件的链接
5. **字幕文案** - 为短视频准备的文案
6. **时间线信息** - 关键日期、地点、人物、事件

### 🎥 短视频制作流程

1. **获取邮件内容** - 查收每日推送的邮件
2. **提取字幕文案** - 使用生成的字幕文案部分
3. **参考时间线** - 了解事件的关键时间点和人物
4. **查看原文链接** - 验证信息的真实性和完整性
5. **制作视频** - 使用提取的信息制作专业的短视频

### 🔧 故障排查

**邮件发送失败**：
- 检查 `.env` 文件中的邮箱和密码
- 确认Gmail已开启应用专用密码
- 检查网络连接和防火墙设置

**没有获取到数据**：
- 检查数据源网址是否可访问
- 验证爬虫的HTML解析规则
- 查看日志文件了解详细错误

**字幕生成不理想**：
- 调整 `content_processor.py` 中的提取参数
- 优化关键词和句子选择算法
